# QA Portfolio Template

Шаблон портфолио с меню в хедере:

- **Связаться**: Telegram + Email + «Скопировать email»
- **Моё резюме**: HH + GitHub

Все данные в `data/profile.json`.

## Как посмотреть новый интерфейс локально

1. В корне проекта запустите сервер:

```bash
python3 -m http.server 4173
```

2. Откройте в браузере:

- Главная: `http://127.0.0.1:4173/`
- Кейсы: `http://127.0.0.1:4173/cases/`
- Чеклисты: `http://127.0.0.1:4173/checklists/`
- Тест-планы: `http://127.0.0.1:4173/test-plans/`
- Инструменты: `http://127.0.0.1:4173/tools/`
- Обо мне: `http://127.0.0.1:4173/about/`
- Контакты: `http://127.0.0.1:4173/contacts/`

Новый UI уже применён глобально через `assets/style.css` ко всем страницам.

Это личный сайт-портфолио Константина Васильева. Здесь нет регистрации, рекламы и подключённой веб-аналитики. Добровольная форма обратной связи отправляет данные только после вашего согласия.

01

Что хранится в браузере

Код сайта использует localStorage только для выбранного языка и отметки о закрытии информационного уведомления. Эти значения остаются на вашем устройстве и не отправляются владельцу сайта.

02

Cookies и трекеры

Код портфолио не устанавливает рекламные или аналитические cookies и не подключает пиксели слежения. При переходе к отправке формы FormSubmit и CAPTCHA могут обрабатывать технические данные по собственным правилам.

03

Технические данные хостинга

Сайт размещён на GitHub Pages. По документации GitHub, IP-адреса посетителей регистрируются и хранятся GitHub в целях безопасности независимо от наличия аккаунта.

04

Проверка API Lab

При открытии страницы API Lab браузер автоматически отправляет GET-запрос к qa-api-lab.onrender.com, чтобы разбудить демо и показать его статус. Render и хостинг приложения могут получить IP-адрес и технические данные запроса. Ответ используется на странице только для индикатора готовности.

05

Внешние ссылки

Telegram, RuStore, Google Drive, Mail.ru и другие внешние сервисы открываются только после нажатия на ссылку. На их страницах действуют собственные правила приватности.

06

Форма обратной связи

При отправке формы имя, email, сообщение и выбранный файл передаются сервису FormSubmit, а затем в почтовый ящик владельца сайта. Цель обработки - получить обращение и ответить на него. Отправка добровольна и доступна только после отметки согласия.
